# CUW2026 engine and managed services

`scripts/cuw_2026.py` never loads a vendor PE or implicitly creates a device,
browser or network connection. Explicit operations use injected host primitives.
`identity_2026` admits only exact original/reconstructed
CUW2026 registry identities. A registry match is provenance, not execution proof.

`configure_2026` reads the exact32-byte native call stack (`I I d d I I`), retains
the unused words in its original argument bytes, initializes the four zeroed CPU
counter arrays and the native `-1` CPU/source maps, and rejects configuration
after loading with native exception code7. The meaning of the two floating
scalars is deliberately not guessed. `native_vin` preserves the17-byte input
check and its NUL/0xFF/question-mark terminators. `id_conversion_rows` decodes
the exact21-byte source rows, including native partial-hex parsing and count0's
no-mutation behavior.

`EngineStatus2026` ports the actual receiving/result/programming/key status
branches and the clear-status guard. It includes priority collisions, not only
one condition at a time. Its status methods return the cleanup-helper requirement
where the native export has that side effect. It does not start a worker, pretend
that status observations prove successful programming, or marshal progress arrays.

`native_protocol` uses the actual public connection mapping: SIL3,
Ethernet0x800f, and default6. P5-Unified/Phase6 select CANFD0x8012 only when
the selected node's `DiagCommProtocol` equals the actual common-definition string
`02`. `connect_j2534` and `disconnect_j2534` call the concrete2026 J2534
implementation, preserving4007/4008 guards and the1000ms timeout. Ethernet
requires an explicitly selected0500 device;0404 fails before provider events.
The injected0500 discovery/resource/connect path is exercised by a fake host.
Physical Ethernet and the complete48-owned device module remain unconfirmed.

* `read_file_header(bytes)` finds the first ASCII case-insensitive
  `[DataCompression]` and decodes its prefix as Shift-JIS. Native result0 requires
  a nonzero marker offset; offset0/no marker produces result2 and empty text.
* `extract_zip(bytes, source_name)` preserves all source input. For `.cuwc` or
  `.scuw`, it skips the marker and exactly one following byte; other suffixes use
  the unmodified ZIP. It returns immutable named members. Bounded expansion,
  duplicate and traversal rejection are explicit host safety policy; native
  extraction overwrites files and is not used here.
  The declared native Shift-JIS encoding maps to Windows CP932, including its
  vendor extensions. `read_header_buffer` retains mixed-wrapper truncation,
  NUL termination and the no-mutation rule on nonzero native status.
* `write_new_file` and `write_new_tree` produce new outputs only. Input paths are
  read through `local_files.read_regular`; destination parents are opened without
  following symlinks. Tree-copy cancellation removes its owned partial tree.

`serialize_object` ports the Newtonsoft wrapper's Boolean-to-Formatting mapping
for bounded JSON primitives. Its cumulative4096 expanded-value budget also
counts shared containers, so small Python DAGs cannot expand exponentially.
A conservative encoded-size budget is charged before encoding strings, keys,
indentation and CRLF. CLR reflection, custom converters, arbitrary CLR
objects and all Newtonsoft overloads are outside that function's contract.

`vehicle_info_from_memory` interprets the actual32-bit writer structs in an
