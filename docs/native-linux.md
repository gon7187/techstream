# Нативный Linux: текущий рабочий срез

Нативная рабочая область читает параметры и диагностические DDB Techstream в GTK4/libadwaita. Доступны системы, определения ошибок/стоп-кадра/единиц, числовой пересчёт и нативная USB-проверка версии MongoosePro JLR. Реальные показания и полный диагностический движок ещё требуют переноса; [матрица функций](full-port.md) отделяет их от уже работающих слоёв.

```sh
cd techstream
./techstream
```

Требуются уже установленные Python, PyGObject/GTK4, libadwaita, libusb и `unshare`. Launcher запускает приложение в отдельном user/network namespace. Внешние IP-маршруты туда не переносятся; обычный запуск не требует root и не меняет firewall. Ошибка создания namespace прерывает запуск без перехода к запуску с сетью. Прямой запуск `python techstream.py` обходит эту изоляцию.

## Работа с интерфейсом

- «Параметры»: выберите регион и группу. Поиск слева фильтрует имя и путь группы; поиск над таблицей — слова имени/единицы/пути. «Во всех группах» ищет по всему выбранному региону. В «Избранном» поиск ограничен сохранёнными группами этого источника.
- Звезда сохраняет группу в `~/.local/share/techstream/saved.json`; учитывается `XDG_DATA_HOME`. Каждый регион и внешний источник имеют отдельный список. При повреждении файла запись отключается, исходный файл сохраняется; путь показан в сообщении.
- «Экспорт CSV» сохраняет все найденные записи, включая короткое имя, ID параметра DDB, категорию преобразования единиц, исходные байты и SHA-256. UTF-8 с BOM, формулы электронных таблиц нейтрализованы апострофом. Файл публикуется атомарно; при ошибке существующий файл сохраняется. Таблица показывает до 1000 совпадений, экспорт не обрезается.
- Кнопка информации показывает путь и SHA-256 CT. Двойное нажатие на строку или Enter открывает исходные поля параметра; содержимое можно копировать.
- «Адаптер» показывает пассивный список USB. Для JLR `18e1:0104` кнопка «Проверить адаптер» открывает нативный USB-сеанс, читает firmware/bootloader/serial и закрывает его; запросов в ЭБУ нет. Подробности и границы: [jlr-native.md](jlr-native.md). При обновлении списка прежний результат сбрасывается; переподключение во время проверки отклоняется.
- «Системы и ошибки» загружает Toyota.ddb и M_English.ddb выбранного региона, показывает связанные файлы ЭБУ, определения DTC, параметры стоп-кадра, текстовые состояния и единицы. Двойное нажатие открывает источник/SHA и исходные определения пересчёта. Системы берутся из базы; это не результат сканирования автомобиля. «Документация» читает локальные руководства.
- Кнопка папки принимает как сам `PIDGroup`, так и папку комплекта с любым доступным регионом. Отсутствующие данные и неподдерживаемые CT отображаются с ошибкой; остальные группы остаются доступны.

Горячие клавиши: `Ctrl+F` — параметры, `Ctrl+G` — группы, `Ctrl+E` — экспорт, `Ctrl+R` — перечитать источник, `Ctrl+Q` — выход. При ширине до 1100 px навигация и список групп открываются кнопками в заголовке. Загрузка идёт в фоне; устаревший результат после переключения региона не подменяет текущие данные.

`./techstream --demo --smoke-test` проверяет учебные ресурсы, три режима сеанса (обзор, графики, калибровки), а также окно, фильтры, поиск по региону, избранное, CSV, документацию, USB-список, переключение региона, настоящие DDB описания DTC/стоп-кадра и сброс USB-кеша при refresh/replug на mock-инвентаре. Для избранного и CSV используется временная папка; пользовательское избранное не меняется. Автоматический smoke не открывает физические USB устройства.

## Настоящий каталог параметров

Источник по умолчанию: `artifacts/extracted/techstream-18-application/Techstream_Data_NA/PIDGroup`. Проверены строгим парсером все три региона, без ошибок:

| Регион | Группы CT | Записи |
| --- | ---: | ---: |
| NA | 1284 | 94 134 |
| EU | 1388 | 96 308 |
| JP | 1274 | 99 952 |
| Всего | 3946 | 290 394 |

```sh
python scripts/pid_catalog.py list
python scripts/pid_catalog.py show 'Brand/1/2ndary Air.CT'
```

Поддерживаемый CT-диалект: заголовок 66 байт, версия `2/52`, количество `uint16_le` по смещению `0x40`; затем три строки `uint16_le byte_length + UTF-16LE`: `name`, `short_name`, `unit`. Это сохранённые снимки соответствующих полей списка параметров. Хвост записи `<IHH>`: параметр DDB (native использует младшие 16 бит), категория преобразования единиц, сохранённое поле списка. Последнее поле равно нулю во всех 290 394 исходных записях; native переносит его десятичной строкой во внутреннюю запись, более узкий смысл не присваивается. Хвост файла — 16 нулевых байт, `uint16_le 4`, восемь нулевых байт. Парсер проверяет фиксированные поля, длины, UTF-16, count и точный EOF.

Точная цепочка: DDB Freeze u16+56 → GetDatMonList command+8 → CommandAPI API item+0 → внутренний ParameterRow+0 → CT. Категория: Unit u16+6 → command+0x52 → API item+0x22 → ParameterRow+0x10 → CT. Writer `Techstream.exe` VA `0x9c18c0`; native reader `0x9bdd10` игнорирует сохранённые short_name/unit/category, оставляет ID и сверяет его с текущими доступными параметрами. Это внутренний ID монитора, не OBD service PID. Подробные инструкции: `analysis/evidence/fullport-ct/`.

Пример исходной группы `Brand/1/2ndary Air.CT`: SHA-256 `2d840eaf1051a8c6fdb5bf277f00881c791a99ddc637a9200f422db500531215`, десять записей, включая `Engine SPD/rpm`, `Throttle POS/%`, `FUEL press/MPa`.

## Офлайн-профиль исходного приложения

```sh
python scripts/build_offline_profile.py \
  artifacts/extracted/techstream-18-application \
  artifacts/extracted/techstream-18-offline-profile
```

Команда требует новую выходную папку и публикует полную копию атомарно. В существующей созданной копии изменены 60 конфигов / 1632 строки: `AvailableFunction/TISFunction=0`, прямые внешние HTTP(S) authorities заменены на `127.0.0.1`. Пути, query, порты и исходное XOR-FF/текстовое кодирование сохранены. Настоящие loopback endpoints сохранены. Манифест в корне копии содержит поля до/после и SHA-256. Все 6400 оригинальных файлов сверены; остальные файлы копии идентичны источнику.

Это изменение конфигурации Windows-приложения, а не его Linux-перенос или доказательство полного запрета сети. URL внутри бинарников и percent-encoded вложенные URL в query остаются исходными. Указанный native launcher изолирует только запускаемый им Linux-процесс; Windows EXE не запускались.

REA отдельно проследил `TisServiceSoftwareUpdateCheck` → `FUN_10010750`: COM-объекты, `EndPointURL`, `ProxyServer`, `Timeout`, `ConnectTimeout` и XML softwareUpdateCheck. Evidence `ev_8a296f6953bd696c3871655054af2e24fab5db1791aeb5cd46acbfcbb42487dc`, bundle `analysis/evidence/tis-core-services.json`. Наличие единственного `TISFunction=0` не доказывает, что каждый сетевой caller исходной программы отключён.

Собственный восстановленный framing Mongoose описан в [mongoose-protocol.md](mongoose-protocol.md).

## Сеанс из записи

В разделе «Сеанс диагностики» выберите обзор систем, график параметров или идентификаторы калибровки. «Воспроизвести пример» выбирает соответствующую синтетическую запись. «Открыть запись» читает ваш локальный файл; режим и число отсчётов должны соответствовать записанным запросам. Ошибка порядка/содержимого останавливает воспроизведение без подстановки ответов.

Все три режима экспортируют JSON. Источник записи защищён от перезаписи отчётом. Числа в интерфейсе округляются для чтения; JSON сохраняет декодированную точность. График переключает параметр и использует номер отсчёта по оси X. Реального времени автомобиля запись не подразумевает.
