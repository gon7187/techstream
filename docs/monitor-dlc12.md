The observed device must be4; the buffer identity must equal the selected category, as native4900 writes that category to buffer+468.

Metadata comes from the shared selected Freeze/PhyData/Unit/PatDisp producer. Category68 requires explicit `DLC12VoltageState` and, in mode1, per-signal `DLC12VoltageObservation` values. Setup IOCTL selection, four WORD samples, DWORD multiplication wrap and division follow native6490. `SelectedDLC12Monitor.commands` contains constructor105 followed by SetupPair10A, start10C and stop10E. Constructor inputs come from the first selected function6B row, its first matching communication row and variable-table send/mask values; lengths must be1/2. Commands bind through `NativeDmciCommand.from_neutral`, including the shared native list/buffer cores. Repeated runtime setup omits constructor105 and sends total length0 while retaining the registered buffer identity.

`DLC12MonitorRuntime` uses `NativeVimClient` directly. This is the native DMCI path, rather than a fabricated vehicle diagnostic request loop. Capture starts10C, polls10D with buffer header identities, routes matching interface chunks into the shared native packet reader, preserves split-packet bytes and timestamps, and stops10E after success, failure, cancellation or budget exhaustion. Unknown reply identities are ignored, matching DataListIF28890. Native integer division ignores incomplete notification tails. The trailing count requests stop. Disposal attempts106 twice and ChangeMode0 even after cleanup failure, matching native27f20. Transport/notification errors prevent reuse of the faulted runtime.
