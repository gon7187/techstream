# CUW2026 Unified and Ethernet

`scripts/programming_2026_unified.py` is a source-specific implementation over
`NativeRuntime2026`. Importing it opens no transport and performs no vehicle action.
The injected provider implements individual J2534 calls, byte reads and key
transforms. It cannot return a full preparation or programming success decision.

The imported context producer joins the validated2026 container to its selected
native parameter row, exact native module identity and2026 communication-address
selector. It does not dispatch an older implementation by matching a DLL name.
Each selection is reproduced from its immutable parameter catalog before I/O.
Authenticated runtime CPUType changes are retained; replaced contexts and forged
parameter rows are rejected. Actual48 `J2534Device2026.primitive` composition is
covered by authored CUW/parameter/discovery/routing/CID checks.

Current implementations include both native CID string layouts, charge-bus01/02
getter start/read/end chronology, Ethernet DoIP
wrapping/address filtering, native pending response timing and timeout/reconnect
branches, discovery/link/routing lifecycle, ESW1 key/routine calls, functional and
periodic messages, SU byte replacement, selected CID execution and Ethernet
preparation and writers. The writers consume imported CPU headers or logical
areas, native fingerprints and original-input archive adapters. Ethernet
whole-package01, ESW1 reset/reconnect and source-backed S-record/binary descriptors
are exercised through the same runtime and actual J2534 adapter. RKS SoftwareID
comes from the source decoder or the retained engine-produced typed identity.
Its native32-byte C-buffer view includes the proven MSVC string layout for short
inline values. The writer copies32 bytes into a zeroed64-byte field. Unrecovered
heap-tail or pointer spans fail explicitly. Normal factory attachments bind the
same engine worker to captured online-controller events for P5, DH, Suzuki wired
and ESW1 keys, including their elapsed time on the shared trace clock. The ESW1
controller and fingerprint consume the same encoded RKS source.
Original key material is absent from representations and reports.
The eight native modules expose22 callable exports and four static address
values. Their source/export/host/test reconciliation includes constructor and
copy/move pointer semantics: move assignment retains the source. The address
values are ADS0100, ESW10103, functionalE400 and J2534 device0E80.
Caller-owned periodic and logical channels retained after preparation require the
same runtime for the following writer. `runtime.close()` releases retained resources.

Private factory checks join the same engine, actual General parser source,
source-bound recovery persistence, shared notification and both captured clock
callbacks across preparation and writing. Ethernet uses the loaded engine's
retained RKS identity. An authenticated300MiB source exercises both small selected
S-record/binary archives and a selected binary transfer crossing5MiB; changing
its backing identity fails before writer I/O and releases preparation resources.
Unified checks cover SMC wired/legacy, P4/P5 central gateway, DH and EachArea,
including native faults, host faults, cancellation and deadlines during
preparation, the initial stub and destructive transfer. Independent source review
and the final family gate remain tracked separately from these synthetic checks.
The two-node cases select global CPU1, verify its distinct fingerprint bytes and
leave CPU0 progress/count untouched.

Native typed failures retain the export BOOL and primary/driver error fields.
Writer fault outcomes read the shared NotificationBool after resource teardown;
an observer is never asked to decide programming success. Unified writer failure
resets progress and preserves native history-enable/default-session ordering.
The final SMC default-session minimum is native DataSize10, including its
four-byte CAN address: six payload bytes pass, five fail with native error1017.
The shared CAN diagnostic helper returns payload bytes; Ethernet retains its
four-byte source/target header when checking native response sizes.
Cleanup preserves the original host exception if timeout, filter or channel
restoration also fails, while recording the cleanup failure. Native typed error
continuations retain their separate export-return rules.

Native observations, host bounds and physical evidence are separate. The global
runtime imposes finite deadlines and cancellation; native pending elapsed time
uses integer local HH:MM:SS, including its hour-wrap rule. No vehicle or adapter
has been used; physical behavior remains `PHYSICAL_UNCONFIRMED`.

Run `python -m unittest discover -s tests -p test_programming_2026_unified.py -v`.
The private source map records exact input/inspection identities, source hashes,
function RVAs and body hashes without publishing original native code or files.

Cancellation stops new diagnostic writes. Charge-bus cancellation releases owned
filters, periodic messages and connection but raises `NativeRestorationCancelled`
with immutable `protocol_restored=False` evidence. It does not claim that the
charge controller or default session was restored. This is explicit bounded host
policy, separately recorded from the original successful cleanup chronology.
