# Techstream для Linux

[English](README.md) · [Начало работы](docs/getting-started.md) · [Участие](CONTRIBUTING.md)

Независимая нативная рабочая область Linux для исследования диагностики Toyota/Lexus: Python, GTK4 и libadwaita. Просмотр локальных ресурсов, диагностических определений и воспроизведение синтетического сеанса без Windows, Wine, адаптера и автомобиля. Интерфейс приложения — на русском; подробная документация преимущественно на английском.

**Это ранняя реализация, а не полная замена Toyota Techstream. Физическая связь с автомобилем имеет статус `PHYSICAL_UNCONFIRMED`.**

![Нативная рабочая область с синтетическими данными](docs/images/workbench.png)

## Запуск

Для консольных инструментов достаточно Python 3.11+; сторонние Python-пакеты и оригинальные базы не нужны:

```sh
git clone https://github.com/gon7187/techstream.git
cd techstream
python -m scripts.session_cli replay examples/diagnostic-session.json --output /tmp/session.json
python -m unittest discover -s tests -v
```

Для окна приложения установите системные зависимости по [инструкции](docs/getting-started.md), затем:

```sh
./techstream --demo
```

Демо создаёт собственные синтетические ресурсы. Названия, коды и значения в них — примеры, а не показания автомобиля и не рекомендации по ремонту. Launcher запускает приложение в отдельном сетевом пространстве Linux; системный firewall не меняется.

## Состояние

| Возможность | Реализовано | Граница |
| --- | --- | --- |
| Рабочая область | Поиск групп/параметров, регионы, избранное, CSV, SHA-256 | Справочные данные, без живых показаний |
| Ресурсы | CT, системы/ошибки/стоп-кадры DDB, числовые преобразования | Поддерживаемые восстановленные форматы; оригиналы нужны отдельно |
| Офлайн-диагностика | Синтетический request/response replay, JSON-отчёт | Проверка кода, не совместимости с ЭБУ |
| Транспорт | Framing Mongoose, identity/version JLR, ISO-TP, кодеки каналов | Синтетические и mock-проверки; физика не подтверждена |
| Скрипты | Разбор структур и ограниченный интерпретатор | Частичная реализация |
| Автомобиль | План дальнейшего исследования | Нет подтверждённых health check, active tests, кодирования и прошивки |

Подробности: [матрица функций](docs/full-port.md), [архитектура](docs/architecture.md), [офлайн-сеанс](docs/offline-diagnostics.md), [план проверки оборудования](docs/hardware-validation.md). Название адаптера и USB ID сами по себе не доказывают совместимость с Toyota.

## Что опубликовано

Только собственный код, документация и синтетические примеры. Оригинальные комплекты Toyota/Lexus, руководства, установщики, драйверы, ключи, активаторы и извлечённые базы в репозиторий не входят. Нужные данные следует получать отдельно с необходимыми правами: [локальный импорт](docs/getting-started.md#local-resource-import).

[MIT](LICENSE) распространяется на авторские материалы проекта и не предоставляет прав на сторонние продукты и данные. Проект не связан с Toyota, Lexus и производителями адаптеров и не одобрен ими.

Для разработки и отправки изменений: [CONTRIBUTING.md](CONTRIBUTING.md). Перед публикацией логов и аппаратных трасс: [SECURITY.md](SECURITY.md).

Экран сеанса также показывает графики по отсчётам и CALID/CVN из записей. Восстановленные native-команды Toyota описаны в [toyota-protocol.md](docs/toyota-protocol.md), CSDF/SRP — в [script-vm.md](docs/script-vm.md). Это не подтверждает физическую совместимость автомобиля.
